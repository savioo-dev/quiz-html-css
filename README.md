# Quiz HTML e CSS

Projeto de um quiz sobre fundamentos de HTML e CSS, desenvolvido com HTML5 e CSS3.

A aplicação apresenta perguntas sobre conceitos fundamentais do desenvolvimento web, utilizando uma interface organizada, responsiva e com atenção às boas práticas de acessibilidade.

# Sobre o projeto

O objetivo deste projeto é praticar a construção de páginas web com HTML semântico e CSS moderno, explorando recursos de estruturação, estilização e responsividade.

# Tecnologias utilizadas

- **HTML5:** estruturação do conteúdo e utilização de elementos semânticos.
- **CSS3:** estilização, organização do layout e adaptação para diferentes tamanhos de tela.

# Funcionalidades

- Formulário de identificação do participante.
- Perguntas sobre fundamentos de HTML.
- Perguntas sobre fundamentos de CSS.
- Alternativas de resposta utilizando campos de formulário.
- Navegação por âncoras entre as seções.
- Layout responsivo.
- Estilização de estados de foco e seleção.

Atualmente, o projeto apresenta a interface do questionário e utiliza os recursos nativos de formulário do navegador. A correção automática das respostas e o cálculo da pontuação ainda não foram implementados.

#Conceitos praticados

- Estrutura semântica do HTML.
- Formulários e campos de entrada.
- Organização de conteúdo com Flexbox e CSS Grid.
- Variáveis CSS.
- Pseudo-classes e seletores modernos.
- Media queries.
- Acessibilidade e navegação por teclado.
- Design responsivo.

# Melhorias futuras

- Implementar correção automática das respostas com JavaScript.
- Calcular e apresentar a pontuação final.
- Exibir feedback para cada resposta.
- Adicionar uma funcionalidade para reiniciar o questionário.
